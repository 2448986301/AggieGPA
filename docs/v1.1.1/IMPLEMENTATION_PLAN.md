# v1.1.1 implementation plan

The update is an in-place, data-preserving redesign of v1.0/v1.1. P0 is the student flow: course, grade breakdown, assignment or exam, score, current course grade, target, and projected GPA. Existing calculation, import, Siri, notifications, backups, privacy, and advanced grading capability remain in the product.

Phase 0 records the baseline. Phase 1 exposes and verifies the existing calculation engine through a short student path. Subsequent phases redesign Today, Courses, GPA, advanced disclosure, localization, onboarding, tests, and visible device validation.
