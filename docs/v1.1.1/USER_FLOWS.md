# User flows

1. Add a course to the selected term.
2. Choose a grade-breakdown template, import a syllabus, or open manual setup.
3. Use Add Assignment or Add Exam from the course page.
4. Tap an item and record earned and possible points.
5. Read the immediately updated Current Course Grade and category averages.
6. Open What Do I Need? for the target estimate. This never replaces the final recorded grade.
