# UX audit

Baseline findings: the main tab names were administrative, course grade actions were hidden in a menu, the default detail page surfaced calculation terminology, and score entry required a full editor. P0 addresses the course-detail path with direct setup, direct assignment/exam creation, and a dedicated score form.

Remaining audit work is tracked for Today, Courses, GPA, Settings, onboarding, and all empty states in the subsequent phases.
